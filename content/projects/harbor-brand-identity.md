## Overview

Harbor Brand Identity is a placeholder identity project for an independent studio whose work depends on trust, craft, and close collaboration.

## Approach

The visual language pairs quiet typography with a small number of repeatable graphic devices. The website uses the same system rather than introducing a separate digital style.

## Outcome

The placeholder system creates a coherent identity that can scale from a simple landing page to a fuller studio site.
